# Programming Challenges Roadmap (Python)

My solutions to the [retosdeprogramacion.com roadmap](https://retosdeprogramacion.com/roadmap/), written in Python to practise programming fundamentals.

## How to run

Each challenge is a standalone script. Run it from the project root:

```bash
python 00_syntax_variables.py
```

Python version used: **3.14.5**. No external libraries are needed, only the standard library.
